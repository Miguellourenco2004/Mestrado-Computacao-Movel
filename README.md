# ⛏️ MineQuest



## About the Project



**MineQuest** is a mobile Android application developed as part of a **Master's in Mobile Computing**. Inspired by the aesthetics of the Minecraft universe, this project combines geolocation and real-world interaction, allowing users to explore the map, complete daily *quests*, gather resources, interact with other players in the chat, and compete for a top position on the leaderboard.

---

## Technologies Used



The application was developed using the most modern and recommended tools for native Android development:

* **Language:** [Kotlin](https://kotlinlang.org/)

* **User Interface (UI):** [Jetpack Compose](https://developer.android.com/jetpack/compose) (Material Design 3)


* **Architecture:** MVVM (Model-View-ViewModel)


* **Navigation:** Jetpack Navigation Compose


* **Maps:** Google Maps SDK for Android + Maps Compose (with a custom map style for the game's aesthetics).


* **Backend as a Service (BaaS):** [Firebase](https://firebase.google.com/)

* **Firebase Authentication:** User management (Register and Login).


* **Firebase Realtime Database / Cloud Firestore:** Real-time synchronization for Chat, Inventory, Quests, and Ranking.




* **Custom Fonts:** Native `minecraft.ttf` font imported for Compose.

## Project Structure (Architecture)



The project follows an **MVVM**-based architecture, organizing the separation of responsibilities. Below is the main structure inside `app/src/main/java/com/example/minequest/`:

```text
com.example.minequest/
│
├── data/                  # Data Layer (Repositories)
│   └── QuestRepository.kt # Manages the quest fetching logic
│
├── model/                 # Data Models (Data Classes)
│   ├── User.kt            # User Structure
│   ├── DailyQuest.kt      # Daily quests structure
│   ├── InventorySlot.kt   # Block inventory structure
│   └── ...
│
├── navigation/            # Jetpack Compose Navigation Logic
│   ├── NavGraph.kt        # Route mapping between screens
│   └── Screens.kt         # Screen names definition (e.g.: "map_screen")
│
├── ui/theme/              # Design System and Custom Themes
│   ├── Color.kt           # App color palette
│   ├── Theme.kt           # Main Compose theme
│   └── Type.kt            # Typography (including the Minecraft font)
│
└── Views & ViewModels     # Visual Components and Business Logic
    ├── MainActivity.kt    # Application entry point
    ├── Login.kt / Register.kt         # Authentication Screens
    ├── Map.kt / MapViewModel.kt       # Google Maps integration and location logic
    ├── MineBlock.kt / MineBlockViewModel.kt # Block gathering mechanics (Mining)
    ├── Profile.kt         # Profile screen and inventory view
    ├── Ranking.kt         # Global leaderboard table
    └── Chat.kt / ChatViewModel.kt     # Community messages

```

## How to Configure and Run the Project



To run this project on your local machine, you need to configure two main external services: **Google Maps** and **Firebase**.

### 1. Prerequisites



* Android Studio (Ladybug version or higher recommended).


* JDK 17 or higher.


* Physical device or Emulator with Android 7.0+ (API 24+) and Google Play Services enabled.



### 2. Firebase Configuration



The application requires the `google-services.json` file to connect to the backend:

1. Access the [Firebase Console](https://console.firebase.google.com/).


2. Create a new project (e.g., "MineQuest").


3. Add an Android app to the project with the exact Package Name: `com.example.minequest`.


4. Download the generated **`google-services.json`** file.


5. Paste the file inside the `app/` folder of the cloned project.


6. In the Firebase console, make sure you enable the following services:


* **Authentication** (Email/Password Method).


* **Realtime Database** or **Firestore** (Adjust the security rules to allow read/write access to authenticated users).





### 3. Google Maps API Configuration



The map and locations depend on the Google Maps API:

1. Access the [Google Cloud Console](https://console.cloud.google.com/).


2. Create a project (or use the same one generated by Firebase) and enable the **Maps SDK for Android**.


3. Generate an **API Key** in credentials.


4. Replace the key in the project:


* *Attention:* The project currently has a key inserted directly in the `AndroidManifest.xml` (e.g., `AIzaSy...`).


* **Security Recommendation:** Remove the key from the Manifest, add `MAPS_API_KEY=your_key_here` in the `local.properties` file (which does not go to GitHub), and use the Secrets Gradle Plugin to inject it securely.





### 4. Compile



After configuring the files, open Android Studio, click on *Sync Project with Gradle Files*, and then on **Run (Shift + F10)**.
